# 🚛 TransitOps – Smart Transport Operations Platform

A modern **Role-Based Fleet & Transport Management System** designed to simplify fleet operations through centralized vehicle management, driver administration, trip planning, maintenance scheduling, fuel & expense tracking, and business analytics.

Developed as a responsive single-page web application with an enterprise-style dashboard and real-time operational workflow.

---

## ✨ Features

### 🔐 Authentication & Role-Based Access Control
- Secure Login System
- Role-Based Access Control (RBAC)
- Login Attempt Protection
- Account Lock after Failed Attempts
- Session Management
- Four User Roles:
  - Fleet Manager
  - Dispatcher
  - Safety Officer
  - Financial Analyst



Launch
